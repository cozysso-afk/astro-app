## 핵심 계산 변경

1. **장기:** 양방향 진행·솔라아크·장기 트랜짓과 원본 진행각 보존은 유지. 장기 실패 시 중기 근거 평가와 빠른 표본을 생략한다.
2. **중기:** Lunar Return(달 회귀) 근거만 중기 점수에 들어간다. 정의상 항상 존재하는 달 자체의 복귀 합은 제외한다. Solar Return(태양 회귀), Mercury Return(수성 회귀), Venus Return(금성 회귀), Mars Return(화성 회귀)은 계속 계산하되 단계별 배경·추적 근거로 남긴다. 배경 회귀 점수는 별도 `mid_context_score`이며 중기 관문이나 최종 가중합에 더하지 않는다.
3. **단기:** 단계 필수 행성 + 관련 대상 + 주요 각 + 자체 강도≥12 + 0≤오브<1도가 모두 필요하다. 생략/비정상 오브, 무한 강도, 무관한 대상, 퀸컨스 각은 단계 관문에서 거부한다.

| 단계 | 필수 행성 | 허용 대상 |
|---|---|---|
| 감정 | 달·금성 | 태양·달·금성 |
| 연락·재접촉 | 수성 | 태양·달·수성·금성 |
| 실제 만남 | 화성 | 달·금성·화성·ASC(상승점)·DSC(하강점) |
| 관계 재정의 | 금성·태양 | 태양·달·금성·DSC(하강점) |

각은 합·육십분위·사각·삼각·대립을 허용한다. 사각/대립은 사건 활성 근거이며 긍정적 결과의 보장이 아니다. 기존 장기35/중기25/촉발12와 35/25/25/15 가중치를 올리거나 조작하지 않았다.

`eligible`은 기존 수치 관문+검증 의미를 유지한다. `raw_numeric_gate_pass`는 순수 수치 관문, `hierarchy_eligible`은 수치+검증+단계 촉발, `selection_eligible`은 해당 집합 안의 공개 국소 피크다. 선택 ⇒ 계층 ⇒ 수치 관문 관계가 유지된다.

각 단계 진단에 total/long/medium anchor/raw numeric/semantic/hierarchy/local peak 및 미래 건수·비율을 분리했다. 중기는 장기 통과 후, 빠른 촉발은 중기 통과 후에만 평가하므로 생략된 점수 0은 계산한 반사실 점수가 아니다. `medium_anchor_evaluated`와 `fast_trigger_evaluated`를 명시한다. 기존 진단 필드 별칭은 유지했다.

- 회귀 주기의 정확 UTC 시작점 조합을 키로 요청 내부에서 중기 근거를 재사용한다. 다른 커플·다른 요청으로 캐시를 공유하지 않는다.
