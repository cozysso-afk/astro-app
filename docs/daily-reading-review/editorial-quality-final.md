# 일일 해설 품질 검수 — 2026-11-04 최종

## 판정
두 가상 프로필·날짜에서 **핵심 이해와 날짜별 차이 기준 통과**. 근거 없는 선택적 예외(change_condition)는 일일 문서에서 제외한 상태로 승인했다. 전체 원고를 새로 쓰거나 서버가 대체 해설을 만들어 넣지 않는다. 운영 반영과 실제 로그인·생성·모바일·저장 이미지 검증도 완료했다. 후속 표시 보완은 [운영 기록](production-rollout-2026-11-04.md)에 구분해 기록한다.

각 작업은 기존 최대 2회 호출 안에서 완료됐다. 최초 본문 생성과 제목·요약/실제 오류 필드 편집을 분리했다. 예시를 손으로 써서 생성 결과처럼 제시한 것이 아니다.

## 고친 원인
- 일일 요청에서 주간·장기운세용 장문 지시를 분리했다. 분야별 독자 질문을 먼저 답하고 제목·요약을 나중에 작성한다.
- 원래 계산의 source_topics와 날짜 표현 조건(time_context)이 전달되지 않던 문제를 고쳤다. 이미 축약된 분야 근거를 다시 앞 5개로 자르던 과정도 제거했다.
- 전 분야를 다시 쓰던 편집은 폐기했다. 제목·요약 및 실제 실패 필드만 수정하며 근거 ID는 수정할 수 없다.
- 모든 분야에 예외를 강제로 채우던 규칙을 제거했다. 현재 일일 자료는 해석을 무효로 만드는 현실 조건까지 증명하지 않으므로 change_condition은 표시하지 않는다. 원문은 provider trace에 남고, 제목·요약·분야 설명·행동·근거는 그대로 유지된다.
- 비일일 기간의 계약과 계산 결과는 바꾸지 않았다. 일일 기본 모델은 검수한 Gemini 3.7로 설정했다. 명시적으로 선택한 모델은 존중한다.

1. 편집 검토: 상충하는 지시와 추상적인 제목의 원인 확인.

## 검증 범위와 남은 제한
검수한 두 입력의 일일 종합과 기본 여섯 분야에 대한 판정이다. 모든 사용자·날짜 또는 주간·재회·궁합의 품질을 보장하는 검증은 아니다. 최종 예외 제외 정책은 동일한 실제 생성 결과를 로컬에서 재생해 검사했으며, 불필요한 추가 유료 생성을 하지 않았다. 운영 배포 후 별도 가상 프로필로 새 해설 1건을 생성해 검증했다. 테스트용 함수는 추가 호출이 발생하지 않도록 중지했다.
