# 별빛의 운명 — 홈화면 로그인·유리 테마·계산 점검

기준: main `5f73587808e1349fb9a0358d04087873d694a2aa`.
상태: 검토용 변경. 운영 배포 및 실제 iPhone 인증/시각 검증 미완료.

## 홈화면 로그인

manifest의 display=standalone, start_url=/, scope=/ 및 Apple standalone meta는 이미 정상이다. 기존 AuthGate는 메일 링크를 누르는 경로만 제공하며, 메일 앱에서 열린 브라우저의 인증을 홈화면 앱으로 이전할 방법이 없다. 제공된 새 설치 URL과 실제 iOS 리다이렉트는 확보하지 못했으므로 도메인 변경까지 원인으로 확정하지 않는다.

추가한 경로: 인증 메일의 **사용하지 않은** 로그인 링크를 길게 눌러 복사 → 홈화면 앱의 인증 입력란에 붙여넣기 → 그 앱에서 Supabase verifyOtp로 검증 → 기존 서버 allowlist 확인. 앱 밖으로 이동하지 않으며 기존 이메일 템플릿을 유지한다. 링크 복사는 임시 사용성 보완이며, 장기적으로는 이메일에 숫자 OTP를 포함하고 앱 안에 코드 입력을 제공하는 편이 더 간단하다. 이번 작업에서 운영 이메일 템플릿을 바꾸지 않았다.

보안: 동일 Supabase HTTPS origin의 /auth/v1/verify만 수락, 이메일 로그인/변경 type만 허용, redirect_to 무시, URL의 세션 토큰 및 외부 주소 거부. 입력 링크는 제출 시 React state에서 지운다. 인증 이메일 불일치 시 sign-out, 익명 계정 연결은 기존 UUID·email 보호와 클라우드 기록 검사를 유지한다. 인증 메일 발송이나 실제 사용자 세션 조작 없이 mock provider로 검증했다.

manifest에 안정적인 id=/를 명시했다. 설정만으로 메일 앱에서 홈화면 앱으로 강제 복귀한다고 주장하지 않는다. 기존 앱 삭제나 저장 데이터 초기화는 필요하지 않다.

## 디자인·해설

기존 미커밋 연락 문장 개선을 보존. Opal 유리 표면에 로즈·하늘·살구·민트·라일락을 분산하고, 선택 상태는 테두리로도 구별한다. 카드 내부 반사광과 짧은 등장/눌림 효과, reduced-motion 대응. 지속적으로 움직이는 입자·타이머는 추가하지 않았다. 간격을 줄이고 본문 대비를 유지하도록 구성했다.

화면 점검용 Cloud Browser가 탭 목록 조회 timeout과 새 탭 생성 timeout으로 실패했다. 따라서 실제 CSS 합성/스크롤/터치/물리 iPhone Safari 검증은 미완료다. 이전 QA의 성공을 이번 변경의 성공으로 재사용하지 않았다.

## 계산 기반 평가

로컬 계산 파일은 변경하지 않았다. 이번 테스트 결과는 현재 소스와 로컬 계산 의존성에 해당하며 운영 Render의 동일 버전 실행 증거를 대신하지 않는다.

- 핵심 10개 테스트 파일: 77 passed, 16 subtests passed.
- 추가 12개 테스트 파일: 112 passed, 15 subtests passed.
- 합계: 189 passed, 31 subtests passed. 건너뛴 테스트는 보고되지 않았다.
- JPL 기준: 저장된 J2000 및 2024 입춘 2개 시점, 10개 천체 경도 비교, 허용 오차 2 arcsec. 모든 시대·좌표·천체 전체 정확성을 입증한 것은 아니다.
- 절기: 2024년 12절 기준값 및 분수 시간대 변환, 경계 허용 오차 120초.
- 사주: 절입 전후, 진태양시 날짜 이동, 자시 정책, 4주 기준값 확인. 채택한 유파 규칙에 대한 일관성이며 유파 전체의 유일 정답이라는 뜻은 아니다.
- 서양: 하우스·극지/시간대·중간점·시기·출생시간 신뢰도·관계 계산 검사를 포함.
- 태국: 기존 MyHora 라그나 기준표 및 경계, 애스펙트·디그니티·하우스 검사 포함. 현대 서양 천문 좌표와 전통 계산법을 동일한 정확도 개념으로 합치지 않는다.

## 확인된 미완성 범위

1. `integrated_fortune_v1.py`는 신강·신약, 용신·희신·기신, 형·파·해 전체 자동판정을 명시적으로 not_calculated로 반환한다.
2. 사주 기간 해설은 월운·세운의 천간 십성을 5개 해설군으로 연결한다. 연애는 식상/비겁에 한정되어 현재 구간이 다른 군이면 설명이 비어 보인다. 이는 사주 전체 계산 실패가 아니라 해설 연결 범위 부족이다. 컨디션은 연결 키가 비어 있다. 임의 매핑 추가로 채우지 않았다.
3. 태국 요약은 마하탁사/탁사존 생활 영역을 일반 문장으로 설명하며 최종 길흉·정확한 사건 시각 판정은 제공하지 않는다.
4. 연락/재회 등 분야 점수는 수동 정의 가중치·역행 보정·합산 규칙에 기반한다. 예: 수성/금성 역행 재회 활성도 배율 1.10. 이 값은 실증된 사건 확률이나 적중률이 아니다.
5. 기존 외부 기준표의 연도/지역 범위 밖은 추가 검증이 필요하다. 통과 수만으로 예측 성능을 평가하지 않는다.

판정: 천문·역법 및 입력 정밀도 처리는 근거를 제시할 수 있는 수준. 사주·태국의 종합 해설 범위와 사건 예측 신뢰도까지 완성형이라고 표현할 수 없다.
