# 출생시간 불확실 해설의 제외 범위 검토

배포 없음. 이번 작업에서는 DB 변경 및 유료 AI 호출을 하지 않았다.

## 실제 생성 검증의 한계

현재 로컬 환경에 Gemini 인증 정보가 없고 로컬 설정 파일에도 실행 가능한 인증 설정이 없어 최신 수정본으로 실제 AI 호출을 실행하지 못했다. 운영에 미배포 코드를 올려 검증하지 않았다. 아래 결과는 기존 코드를 실행하는 합성 입력 회귀 검증이며 실제 AI 문장 품질 평가가 아니다.

## 확인 및 수정

- provisional 출력 제거 로직이 일부 필드만 열거하고 있어 headline, topic_analysis, decisions, clusters 및 향후 추가되는 중첩 필드를 누락했다. 모든 텍스트 필드에 같은 제외 규칙을 적용한다.
- 기존 검사가 영문 ASC/MC, 하우스 시스템명과 HH:MM 위주여서 한국어 상승궁·하우스·출생차트의 달 및 '오후 3시' 같은 문구를 놓쳤다. 해당 표현을 제외하고 검출한다.
- 관측 데이터의 새 natal_target 필드에도 Moon/ASC/MC 제외 규칙을 적용한다. 현재 움직이는 Moon이 출생 Venus에 연결된 근거는 허용한다.
- 근거 ID는 문장이 아니므로 날짜/인덱스의 '10:10'을 시각으로 취급하지 않는다.
- provisional packet에 불투명한 S:/T: ID와 중첩 observation.target의 출생시간 민감 근거가 남지 않게 한다. 최종 출력의 evidence_refs에서도 교차체계 및 시간창 참조를 제거한다.
- 입력 원문을 변경하지 않고 반환본만 보정한다. 제외한 문장을 근거 없이 새로 채우지 않는다.

## 검증

precisionV2, personalTransitContext, editorialOutput 검사 총 38개 통과, 실패/건너뜀 0. 실제 V22 핸들러를 로드하는 기존 모의 I/O 검사도 포함한다. git diff --check 통과.

새 회귀 케이스는 5개 출력 위치, 정상 transit Moon과 소수 점수 보존, 중첩 natal_target, 불투명 체계 ID 필터링이다. 자연어 전체를 완벽하게 검출하는 의미 분류기는 아니며 다른 표현의 누출 가능성은 실제 생성 표본 검증으로 더 확인해야 한다.

출생시간이 아예 없는 입력의 지원 범위나 기존 precision contract는 변경하지 않았다. 여기서 provisional은 현재 계약상 시간이 입력됐으나 정확성이 검증되지 않은 경우다. 새 AI 결과의 다중 출생정보·기간·상황 비교는 여전히 미실행 상태다.
