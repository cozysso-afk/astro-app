# 해설 10개 관점 검토

기준: PR #123의 f040893855132aba7c113b8ee0a26cc875216af2. 사용자 요청에 따라 서로 다른 실패 조건 10개를 코드 검토·재현 검사·수정 후 회귀 검사했다. 동일 테스트를 열 번 반복한 횟수가 아니다.

| 검토 | 발견/확인 | 조치 |
|---|---|---|
| 1 분야 누락 | AI 응답에 빠진 분야가 화면에서도 사라짐 | 요청한 분야와 계산된 등록 분야를 계산 기반 대체 해설로 유지 |
| 2 정보 부족 | 평균값이 없는 참고 항목에 긍정 문구와 강약 라벨이 붙을 수 있음 | 정보 부족으로 표시, 검증 AI 문장도 평균 없는 항목에 재사용하지 않음 |
| 3 혼합 근거 | 중립·긍정·부정 중 세 번째 방향 생략 | 모든 방향 보존, 크기와 방향 분리 유지 |
| 4 체계 간 맥락 | 참조가 같으면 기간 밖 교차 해설도 사용 | 참조와 선택 기간 포함 조건을 함께 확인 |
| 5 품질 판정 | 실패 단계가 있어도 총점 100이면 통과 표시 | 실패/미확인 단계가 총점보다 우선, 본문과 배지 같은 판정 사용 |
| 6 재회 정보 | 비어 있는 재접점 통계를 보통으로 해석할 가능성 | 유효 평균이 있을 때만 강약·시기·문장 표시 |
| 7 기간 구간 | 종료일이 시작일보다 빠른 구간도 노출 가능 | 역전 및 기간 밖 구간 제외 |
| 8 시각 정밀도 | 25:00 같은 잘못된 시각을 형식만으로 수락 | 시·분 범위 검사, 정밀도 불충족 시 시간 추천 차단 유지 |
| 9 관계 주의사항 | 관계 문맥 적용이 원래 주의사항을 덮어씀, AI avoid 공백이면 주의사항 사라짐 | 기존 주의와 문맥 주의 병기, 공백은 분야별 주의로 대체 |
| 10 점수 의미 | 높은 투자주의는 위험이며 연락 총점은 수신/발신과 다름 | 위험 역방향 순위 회귀 확인, 연락 요약 카드의 일방적 발신 조언 수정 |

## 검증

- 새 재현 검사: `web/src/lib/readingTenPass.test.mjs`의 10개 테스트 모두 통과.
- 함께 실행한 기존 해설·화면 계약·React SSR·체계/관계 검사 포함: Node 208 tests passed, 실패/skip 0. 신뢰성 스크립트의 여러 assertion은 Node에서 하나의 파일 테스트로 집계된다.
- 서버 구조화 출력 및 태국 해설 제한: pytest 24 passed.
- TypeScript/Vite production build 및 git diff --check 통과.
- 기존 UI 계약 fixture 중 부호를 contribution에 넣었던 사례를 실제 엔진 계약(양의 contribution + 별도 polarity)으로 수정했다. 방향이 없는 경우 긍정으로 추정하지 않는 신규 검사는 유지했다.
- 계산값/점수·시기 원본 불변 검사 포함. 추가 AI 호출과 실제 인증 메일 발송 없음.

## 한계와 배포

이 검토는 해설의 근거 충실성·누락·표현 일관성 검사다. 실세계 사건 예측의 정확성 또는 적중률을 입증하지 않는다. 신강·신약, 용신·희신·기신, 형·파·해 전체 등 기존 미계산 범위를 새로 계산하거나 상징 해설로 대신하지 않았다. 사주/태국의 기존 범위는 앞선 opal-pwa-engine-review 문서 참조.

실제 iPhone 및 새 AI 응답의 실사용 시각 검증은 수행하지 않았다. PR #123은 OTP 메일 템플릿 적용을 기다리는 draft이며 이번 변경도 운영 배포하지 않았다.
