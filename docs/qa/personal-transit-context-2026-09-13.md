# 개인 접촉·관측 단계 해설 연결

배포하지 않음. 유료 서비스 비교에서 확인한 개인 출생 대상/시간 단계 설명을 현재 계산 범위 내에서 보완했다.

- 일별 실제 근거의 transit/target/aspect/motion/polarity/orb 및 제공된 하우스 정보만 구조화해 근거 장부에 보존한다. 임의 출생 위치, 시작/종료 시각은 생성하지 않는다.
- 해설용 압축 자료에 같은 transit–natal target–aspect의 관측 날짜와 당시 motion을 묶어 전달한다. 최대 24개 접촉, 선택된 기존 근거만 사용하고 근거 ID를 보존한다.
- 관측 범위는 실제 시작/절정/종료가 아니라는 정책을 명시한다. 적용/분리는 각도에 가까워짐/멀어짐이며 길흉이나 상대의 접근/이탈이 아니다. Exact는 계산 허용범위이며 사건 시각이 아니다.
- 화면의 근거 설명에 운행 행성과 출생 대상의 차이, 가장 큰 기여 근거의 계산된 motion을 풀어쓴다.
- 긴 흐름과 짧은 변화는 제공된 월평균·기간평균·관측 근거를 구분해 종합하도록 생성 지침을 추가했다. 실제 접촉 지속 기간 산출은 이번에 구현하지 않았다.
