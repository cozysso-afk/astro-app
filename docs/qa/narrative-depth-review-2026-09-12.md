# 해설 문장 품질 개선 — 실제 저장본 검토와 수정 후 출력

## 실제 저장본에서 확인한 문제

서버에 저장된 일간·주간·월간·연간 해설의 전체 요약 또는 학업/연락 문장을 읽었다. 개인정보와 원본 해설 전체는 이 문서에 복제하지 않는다.

| 기간 | 확인한 문제 | 수정 |
|---|---|---|
| 일간 | 참고 분야가 빈 행동·주의와 한 줄 해설로 끝남 | 다른 분야에도 펼칠 수 있는 이유·행동·주의 제공 |
| 주간 | 같은 목성–수성 배치를 날짜별로 반복, 낮은 평균과 지원 근거의 관계가 설명되지 않음 | 기간 평균과 개별 근거를 구분하고 확인된 근거 날짜를 명시 |
| 월간 | 약함 band를 중간권으로 풀고 요약에 긴 분야별 원문을 덧붙임 | band와 방향 문장을 일치시키고 요약 보정은 결론·행동·시기로 구성 |
| 연간 | 전체 요약이 여러 분야의 긴 이유를 이어 붙인 문장, 반복적인 관찰 조언 | 이유 원문 재복제를 줄이고 AI 종합 지침에 반복 근거·전체/부분 구분 추가 |

## 수정 후 실제 함수 출력 예시

아래는 개인정보 없는 합성 입력을 현재 앱 함수에 넣어 생성한 검토용 출력이다. 새로운 실사용자 AI 생성본이 아니며 예측으로 읽지 않는다. 입력은 학업 평균 35, 수성–목성 지원 근거와 화성–토성 부담 근거다. 추가 AI 호출은 없었다.
